# SialTV — All Cricket Leagues

SialTV is an independent informational cricket hub covering the world's T20 leagues in one place.

- **Live now:** Nepal Premier League (Season 3, 2026)
- **Coming next:** ILT20 (Season 5), Afghanistan Premier League (2026-27), SA20 (Season 5)
- **Later:** Big Bash League, PSL, IPL and new leagues as their seasons approach

Each league gets its own hub — schedule, points table, teams, results and where to watch — in that league's own colours.

> This is an independent informational website. It is not affiliated with or endorsed by any league, club, board or federation.
